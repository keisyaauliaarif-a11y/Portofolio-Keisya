PORTOFOLIO KEISYA — VERSI FOTO DARI KODE

Tidak ada tombol unggah foto pada halaman website. Gambar ditentukan langsung di index.html melalui atribut src, jadi pengunjung tidak bisa mengganti foto dari halaman.

FOTO PROFIL
1. Buka folder assets.
2. Ganti file foto-profil.png dengan foto kamu (gunakan nama file yang sama), atau ubah src pada elemen img id=profile-photo di index.html.

GAMBAR PROYEK
Di folder assets ada gambar SVG contoh untuk 4 proyek. Ganti file tersebut dengan screenshot proyek kamu, atau ubah atribut src pada masing-masing img di index.html ke nama file screenshot, misalnya assets/edulearn.png.
Nama gambar yang dipakai di index.html: edulearn.svg, koreksi-data-bpjs.svg, deteksi-gesture.svg, desain-figma.svg.

JALANKAN
Buka folder ini di VS Code lalu jalankan index.html menggunakan Live Server. Untuk hosting, unggah seluruh folder beserta folder assets.
